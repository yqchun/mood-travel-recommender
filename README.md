# Mood Travel Recommender

一个根据用户当前心情、出发地、时间、预算和体力，推荐 1～4 天短途旅行方案的 Codex Skill。默认输出 5 个可比较方案，每个方案标注 1～5 星。

## 功能

- 从“想放空”“想换个环境”“想拍照”“想吃东西”等描述中理解旅行需求
- 结合出发地、天数、预算、交通、同行方式和返程时间筛选目的地
- 默认输出 5 个方案（1 个主推荐、4 个备选）；用户指定 3～5 个时严格按指定数量输出。每个方案标注推荐星级，并完整包含交通、住宿、逐日安排、预算、强度、避坑和待核验信息
- 用户强调山水等景观组合时，方案覆盖至少 4 个独立目的地区域和不同景观形态，避免把同一景区拆成多个伪备选
- 生成包含交通、活动、休息、住宿和返程的逐日行程，并写清真实景点访问顺序、每段怎么走、移动与停留时间和撤离路径
- 按推荐日期核验逐日天气，记录适用地点或海拔层级、温度、降雨、风力/雷电、预报发布时间和查询时间，并说明对路线的影响
- 根据天气、海拔和地形给出鞋、衣物层次、雨具、防晒、饮水等穿着装备建议
- 拆分交通、住宿、餐饮、门票和当地交通预算
- 标注已确认、估算、待核验的信息，并提示预约、营业时间、末班车和天气风险
- 支持雨天、低体力和闭馆替代方案

## 适用范围

- 国内本地及周边短途旅行
- 连续 1～4 个自然日
- 独自、情侣、朋友或家庭出行

本 Skill 默认只提供目的地和游玩方案建议，不代替用户购票、订房、支付或确认实时库存。超过 4 天、复杂多城市路线或缺少可靠实时信息时，会明确说明限制。

## 使用示例

```text
我最近很累，想一个人安静地散散心，从上海出发，周末 2 天，预算 1000 元，最好高铁 2 小时内。
```

```text
从广州出发，和朋友去 3 天，想看自然风景、吃当地美食，人均预算 2000 元，不想频繁换酒店。
```

## 推荐结果结构

1. 需求理解
2. 5 个推荐方案（按星级排序；第 1 个为主推荐，其余为备选；每个方案含真实路线顺序、逐日天气和穿着装备）
3. 方案对比
4. 快捷调整选项
5. 信息来源与核验时间

## 安装

将本目录复制到 Codex 的 skills 目录：

```text
~/.codex/skills/mood-travel-recommender/
```

Windows 默认路径通常为：

```text
C:\Users\<用户名>\.codex\skills\mood-travel-recommender\
```

安装后重启或刷新 Codex，即可通过自然语言触发，例如“根据我的心情推荐一个周末去处”。

## 信息核验原则

旅行信息会变化。涉及营业时间、交通班次、门票、预约、住宿政策、天气或节假日影响时，应优先查阅景区、交通运营方、政府或住宿官方页面，并清楚区分事实、估算、建议和待核验内容。
